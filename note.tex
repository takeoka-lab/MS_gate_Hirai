\section{研究主張}
まずは以下の内容についてまとめる。
『単発MS gateから得た有効2量子ビットエラーチャネルをQEC回路中で独立同一に繰り返す近似は、
運動モードの記憶により破れる可能性がある。
本研究では、full spin motion simulationとMarkovian channel compositionを比較し、その差をχ行列・PTM・Pauli近似誤差として定量化する。』

ここで注意しなくては行けないのが、Vinas \& Bermudez, “Context aware gate set tomography”である。

\section{Context-aware gate set tomography: Improving the self-consistent characterization
of trapped-ion universal gate sets by leveraging non-Markovianity}
この論文は、通常のGate Set Tomography(GST)が仮定する「各ゲートは常に同じCPTPマップ」というMarkovian/constant-map仮定が、
トラップイオンのフォノン媒介2量子ビットゲートでは破れることに注目し、
むしろその非マルコフ性・文脈依存性を物理モデルに取り込むことで、GSTを高精度・低サンプル数にできることを示した論文である。
特に対象は Light-shift gate(LS gate) だが、これはMS gateと同じくフォノンを介した幾何位相ゲートである。

さらに、フォノンによる文脈依存性はGSTを壊す邪魔者ではなく、物理モデルに入れれば、むしろ推定精度を上げる資源になる。
